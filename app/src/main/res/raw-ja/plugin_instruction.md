3-Prism Camera は AutoJs6 のカメラプラグインで, スクリプトから写真撮影, ライブフレームの取得, ファインダーのプレビュー表示ができます. 取得したフレームは `ocr`, `barcode`, YOLO などの認識モジュールにそのまま渡せるため, リアルタイムのコード読み取り, 文字認識, 物体検出に使えます.

### はじめに

1. ランチャーから 3-Prism Camera を開き, ファインダー画面で "権限を許可" をタップしてカメラの使用を許可します.
2. "撮影" をタップして試し撮りします. 写真は "写真のプレビュー" に表示されるだけで, 保存されません.
3. AutoJs6 の "プラグインセンター" でこのプラグインを有効にします.
4. スクリプトで `camera` モジュールを呼び出して撮影やフレームの取得を行います. 例は後述します.

### 主な機能

- **ファインダー画面**: ランチャーからプラグインを開くとファインダー画面になり, "カメラを切り替え", ライトのオンとオフ, スライダーやピンチでのズーム, 映像のタップでのフォーカスができます.
- **撮影**: スクリプトは向きを正立させた画像を受け取り, 元の JPEG を指定のパスに保存することもできます. `camera.capture({ ui: true })` ではユーザーがファインダー画面で撮影します.
- **ライブフレーム**: フレームは既定で 640x480, 最大 1920x1080 で, 画面の向きに合わせて正立します. 処理が追いつかないフレームは飛ばして数え, 溜め込みません.
- **プレビュー**: ui レイアウトやフローティングウィンドウの `SurfaceView` をセッションに渡すとファインダーの映像が表示され, フレームの取得や撮影と同時に使えます.
- **カメラの操作**: スクリプトからライト, フラッシュモード, ズーム, 露出補正, タップでのフォーカスを操作でき, それぞれの範囲と現在の値も読み取れます.
- **カメラの占有**: カメラを使えるセッションは同時に 1 つだけです. スクリプトがカメラを使っているときはファインダー画面にそのスクリプトが表示され, "このスクリプトを停止" でカメラを引き継げます.
- **バックグラウンドでの取得**: セッション中は "カメラ使用中" の通知が表示され, AutoJs6 がバックグラウンドにあっても画面がオフでもフレームが届きます. スクリプトが終了するとカメラはすぐに解放されます.
- **既定値**: ファインダー画面右上の "設定" で "既定のカメラ", "既定の解析解像度", "既定の解析フレームレート" を指定できます. スクリプトが指定した値が常に優先されます.
- **診断と更新**: 設定の "診断" には各カメラの対応機能と "現在の使用者" が表示されます. "更新を確認" で公式プラグインインデックスから新しいバージョンを探します.
- **表示の設定**: "言語", "ナイトモード", "テーマ色" は既定で AutoJs6 に従い, 個別に指定することもできます. "ランチャーアイコン" も切り替えられます.

### スクリプトでの使い方

AutoJs6 の Rhino スクリプトでは, グローバルモジュール `camera` でカメラを使います. 次の例は写真を 1 枚撮影し, JPEG を内部ストレージ直下の prism.jpg として保存します:

```js
let img = camera.capture({ path: files.join(files.getSdcardPath(), 'prism.jpg') });
toastLog(img.getWidth() + 'x' + img.getHeight());
img.recycle();
```

次の例は 1280x720 でフレームを取得してバーコードを認識し, 読み取れたらセッションを閉じます. バーコード認識には "プラグインセンター" で ML Kit Barcode プラグインを有効にしておく必要があります:

```js
let session = camera.open({ resolution: '1280x720' });
session.analyze((img) => {
    let text = barcode.recognizeText(img);
    if (text !== null) {
        toastLog(text);
        session.close();
    }
});
events.on('exit', () => session.close());
```

- `analyze` のコールバックで受け取るフレームはコールバックの実行中だけ有効です. コールバックの外で使うときは `img.clone()` で複製し, 使い終わったら `recycle()` を呼び出します.
- `camera.capture` は UI スレッドでは呼び出せません. ui スクリプトの画面のコールバックでは `camera.captureAsync` を使います.
- Node.js スクリプトでは `require('autojs6:camera')` から同じメソッドを使え, 戻り値は Promise です. Node.js と Bun ではプレビューを表示できません.
- 詳しい使い方とエラーコードは [AutoJs6 ドキュメント > Camera](https://docs.autojs6.com/#/camera) を参照してください.

### 動作要件

- Android 7.0 以降. ファインダー画面と設定には AutoJs6 は不要です.
- `camera` モジュールには AutoJs6 6.8.1 以降が必要で, "プラグインセンター" でこのプラグインを有効にする必要があります.
- カメラの権限はプラグイン自身が持ち, AutoJs6 のカメラの権限では代用できません. 設定の "カメラの権限" で許可するか, スクリプトから `camera.requestPermission()` を呼び出します.
- 通知の権限 (Android 13 以降) は "カメラ使用中" の通知の表示に使います. ネットワークの権限は更新の確認にだけ使い, カメラの映像と写真は端末の外に出ません.

### よくある質問

**カメラを開くと `CAMERA_DISABLED` が報告される理由**

Android 11 以降では, AutoJs6 がバックグラウンドにあるときや端末がロック画面のときは, システムがカメラの使用を許可しません. AutoJs6 をフォアグラウンドに戻してから開き直してください. フォアグラウンドで開いたセッションは, その後バックグラウンドや画面オフになってもフレームを取得し続けます.

**カメラが使用中 (`CAMERA_BUSY`) の場合の対処**

カメラを使えるセッションは同時に 1 つだけで, エラーの `details.holder` が使用者を示します: スクリプトのパス, またはファインダー画面を表す `pluginUi` です. そのセッションかファインダー画面を閉じてから開き直してください. ファインダー画面で "このスクリプトを停止" をタップすることもできます.

**写真の保存先**

プラグインは写真を保存せず, システムのギャラリーにも書き込みません. スクリプトが `path` を渡したときだけ, AutoJs6 が JPEG をそのパスに書き込みます.

各メーカーのシステムでの互換性と権限の説明は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Prism-Camera) を参照してください.
