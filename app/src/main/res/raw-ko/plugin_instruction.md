3-Prism Camera는 AutoJs6의 카메라 플러그인으로, 스크립트에서 사진 촬영, 실시간 프레임 수신, 뷰파인더 미리보기를 할 수 있습니다. 받은 프레임은 `ocr`, `barcode`, YOLO 같은 인식 모듈에 바로 넘길 수 있어 실시간 코드 스캔, 문자 인식, 객체 감지에 쓸 수 있습니다.

### 시작하기

1. 런처에서 3-Prism Camera를 열고 뷰파인더 화면에서 "권한 허용"을 탭해 카메라 사용을 허용합니다.
2. "촬영"을 탭해 시험 삼아 한 장 찍습니다. 사진은 "사진 미리보기"에만 표시되고 저장되지 않습니다.
3. AutoJs6의 "플러그인 센터"에서 이 플러그인을 활성화합니다.
4. 스크립트에서 `camera` 모듈을 호출해 사진을 찍거나 프레임을 받습니다. 예는 아래에 있습니다.

### 주요 기능

- **뷰파인더 화면**: 런처에서 플러그인을 열면 뷰파인더 화면이 나타나며, "카메라 전환", 손전등 켜고 끄기, 슬라이더나 핀치로 줌, 화면을 탭해 초점 맞추기를 할 수 있습니다.
- **사진 촬영**: 스크립트는 방향을 바로 세운 이미지를 받으며, 원본 JPEG를 지정한 경로에 저장할 수도 있습니다. `camera.capture({ ui: true })`는 사용자가 뷰파인더 화면에서 직접 찍게 합니다.
- **실시간 프레임**: 프레임은 기본 640x480, 최대 1920x1080이며 화면 방향에 맞게 바로 세웁니다. 처리하지 못한 프레임은 건너뛰고 개수를 세며 쌓아 두지 않습니다.
- **미리보기**: ui 레이아웃이나 플로팅 창의 `SurfaceView`를 세션에 넘기면 뷰파인더 영상이 표시되며, 프레임 수신 및 사진 촬영과 동시에 사용할 수 있습니다.
- **카메라 제어**: 스크립트에서 손전등, 플래시 모드, 줌, 노출 보정, 탭 초점을 제어하고 각 항목의 범위와 현재 값을 읽을 수 있습니다.
- **카메라 독점**: 카메라는 한 번에 한 세션만 사용할 수 있습니다. 스크립트가 카메라를 쓰고 있으면 뷰파인더 화면에 어떤 스크립트인지 표시되며, "이 스크립트 중지"로 카메라를 넘겨받을 수 있습니다.
- **백그라운드 프레임**: 세션이 열려 있는 동안 "카메라 사용 중" 알림이 표시되며, AutoJs6가 백그라운드에 있거나 화면이 꺼져도 프레임을 받습니다. 스크립트가 끝나면 카메라는 바로 해제됩니다.
- **기본값**: 뷰파인더 화면 오른쪽 위의 "설정"에서 "기본 카메라", "기본 분석 해상도", "기본 분석 프레임 속도"를 지정할 수 있습니다. 스크립트가 지정한 값이 항상 우선합니다.
- **진단과 업데이트**: 설정의 "진단" 섹션에 각 카메라가 지원하는 기능과 "현재 사용 중" 항목이 표시됩니다. "업데이트 확인"은 공식 플러그인 인덱스에서 새 버전을 찾습니다.
- **화면 설정**: "언어", "야간 모드", "테마 색상"은 기본적으로 AutoJs6를 따르며 따로 지정할 수도 있습니다. "런처 아이콘"도 바꿀 수 있습니다.

### 스크립트에서 사용하기

AutoJs6의 Rhino 스크립트에서는 전역 모듈 `camera`로 카메라를 사용합니다. 다음 예는 사진을 한 장 찍고 JPEG를 내부 저장소 최상위의 prism.jpg로 저장합니다:

```js
let img = camera.capture({ path: files.join(files.getSdcardPath(), 'prism.jpg') });
toastLog(img.getWidth() + 'x' + img.getHeight());
img.recycle();
```

다음 예는 1280x720 프레임을 받아 바코드를 인식하고, 인식되면 세션을 닫습니다. 바코드 인식에는 "플러그인 센터"에서 ML Kit Barcode 플러그인을 활성화해야 합니다:

```js
let session = camera.open({ resolution: '1280x720' });
session.analyze((img) => {
    let text = barcode.recognizeText(img);
    if (text !== null) {
        toastLog(text);
        session.close();
    }
});
events.on('exit', () => session.close());
```

- `analyze` 콜백의 프레임은 콜백이 실행되는 동안에만 유효합니다. 콜백 밖에서 쓰려면 `img.clone()`으로 복사본을 만들고, 다 쓰면 `recycle()`을 호출합니다.
- `camera.capture`는 UI 스레드에서 호출할 수 없습니다. ui 스크립트의 화면 콜백에서는 `camera.captureAsync`를 사용합니다.
- Node.js 스크립트는 `require('autojs6:camera')`로 같은 메서드를 사용하며 반환값은 Promise입니다. Node.js와 Bun에서는 미리보기를 표시할 수 없습니다.
- 자세한 사용법과 오류 코드는 [AutoJs6 문서 > Camera](https://docs.autojs6.com/#/camera)를 참고하세요.

### 요구 사항

- Android 7.0 이상. 뷰파인더 화면과 설정에는 AutoJs6가 필요하지 않습니다.
- `camera` 모듈에는 AutoJs6 6.8.1 이상이 필요하며, "플러그인 센터"에서 이 플러그인을 활성화해야 합니다.
- 카메라 권한은 플러그인이 직접 가지며 AutoJs6의 카메라 권한으로 대신할 수 없습니다. 설정의 "카메라 권한" 항목에서 허용하거나, 스크립트에서 `camera.requestPermission()`을 호출합니다.
- 알림 권한 (Android 13 이상)은 "카메라 사용 중" 알림을 표시하는 데 쓰입니다. 네트워크 권한은 업데이트 확인에만 쓰이며, 카메라 영상과 사진은 기기 밖으로 나가지 않습니다.

### 자주 묻는 질문

**카메라를 열 때 `CAMERA_DISABLED`가 보고되는 이유**

Android 11 이상에서는 AutoJs6가 백그라운드에 있거나 휴대폰이 잠금 화면에 있으면 시스템이 카메라 사용을 허용하지 않습니다. AutoJs6를 포그라운드로 가져온 뒤 다시 열면 됩니다. 포그라운드에서 연 세션은 이후 백그라운드로 가거나 화면이 꺼져도 계속 프레임을 받습니다.

**카메라가 사용 중인 경우 (`CAMERA_BUSY`)**

카메라는 한 번에 한 세션만 사용할 수 있으며, 오류의 `details.holder`가 사용 중인 쪽을 알려 줍니다: 스크립트의 경로, 또는 뷰파인더 화면을 뜻하는 `pluginUi`입니다. 해당 세션이나 뷰파인더 화면을 닫은 뒤 다시 여세요. 뷰파인더 화면에서 "이 스크립트 중지"를 탭할 수도 있습니다.

**사진이 저장되는 위치**

플러그인은 사진을 저장하지 않으며 시스템 갤러리에도 쓰지 않습니다. 스크립트가 `path`를 넘긴 경우에만 AutoJs6가 JPEG를 그 경로에 씁니다.

제조사별 시스템 호환성과 권한 설명은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Prism-Camera)를 참고하세요.
