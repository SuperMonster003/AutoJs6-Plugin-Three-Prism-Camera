# v1.0.0

###### 2026/11/05

* `힌트` 스크립트 API: [AutoJs6 문서 > Camera](https://docs.autojs6.com/#/camera)
* `힌트` AutoJs6 6.8.1 (6641) 이상이 필요합니다 (정확한 최소 버전은 호스트 쪽 변경이 반영된 뒤 기입됩니다)
* `힌트` 현재 아이콘은 후보 디자인이며 이후 바뀔 수 있습니다
* `기능` 플러그인 골격: Wake 활성화 프로토콜과 플러그인 센터 식별 서비스
* `기능` 카메라 기능 서비스: 카메라는 한 번에 한 세션만 사용할 수 있으며, 사용 중이면 점유자를 알려 줍니다. 카메라를 쓰는 동안 포그라운드 알림을 표시하고, AutoJs6가 종료되면 카메라를 즉시 해제하고 알림도 사라집니다
* `기능` 실시간 프레임: RGBA 프레임을 공유 메모리 3개 (Android 8.1 이상) 또는 임시 파일 3개 (Android 7.0 - 8.0)로 번갈아 AutoJs6에 전달하며, 해상도와 프레임 속도를 지정할 수 있습니다. 제때 처리하지 못한 프레임은 건너뛰고 개수를 셉니다
* `기능` 사진 촬영: JPEG를 읽기 전용 파일로 AutoJs6에 전달하며 너비와 높이, EXIF 방향, 바이트 수, 미러 여부를 함께 알려 줍니다. 화질, 해상도, 플래시 모드를 지정할 수 있습니다. 미러 촬영은 EXIF 방향만 다시 쓰며 다시 인코딩하지 않습니다. 사진 방향을 기록하지 않는 카메라 (예: Android 7.0 에뮬레이터)에서는 플러그인이 90 / 270도 방향을 보충해 기록하므로 사진이 기기를 든 방향대로 표시됩니다 (누락된 180도는 판별할 수 없습니다)
* `기능` 미리보기: AutoJs6가 제공하는 화면에 표시되며 화면을 회전하면 방향도 따라갑니다. 전면 렌즈의 미리보기는 기본적으로 미러링되고, 프레임과 사진은 기본적으로 미러링되지 않습니다. 미리보기를 표시하는 화면이 사라지면 미리보기가 자동으로 멈추고, 프레임 수신과 사진 촬영은 계속됩니다
* `기능` 제어: 손전등, 플래시 모드, 줌 (배율 또는 선형), 노출 보정, 탭하여 초점 맞추기와 측광; 기기가 지원하지 않는 항목 (예: 전면 렌즈의 플래시)은 UNSUPPORTED를 반환합니다
* `기능` 카메라 권한: 권한 없이 카메라를 열면 PERMISSION_DENIED를 반환하며 권한을 요청할 수 있습니다. Android 13 이상에서는 카메라 사용 중 알림을 표시하기 위해 알림 권한도 함께 요청합니다
* `기능` 뷰파인더 화면: 런처에서 열며 렌즈 전환, 손전등, 슬라이더 또는 손가락 오므리기로 줌, 탭하여 초점 맞추기를 지원합니다. 촬영한 사진은 이미지와 해상도만 표시하고 저장하지 않습니다. 전면 렌즈 화면은 미러링되어 표시되고 사진은 미러링되지 않습니다
* `기능` 스크립트에서 camera.capture({ ui: true })를 호출하면 같은 뷰파인더 화면이 열리고, 사진은 바로 스크립트에 전달되며 취소하면 null을 반환합니다. AutoJs6가 백그라운드에 있어 뷰파인더 화면을 열 수 없으면 계속 기다리지 않고 10초 후 UI_REQUIRES_FOREGROUND를 반환합니다
* `기능` 스크립트가 카메라를 사용 중이면 뷰파인더 화면에 해당 스크립트를 표시하고, 그 스크립트를 중지한 뒤 카메라를 넘겨받을 수 있습니다
* `기능` 설정 화면 (뷰파인더 화면 오른쪽 위): 모양 (언어, 야간 모드, 테마 색상, 런처 아이콘), 카메라 및 알림 권한, 기본 카메라, 기본 분석 해상도와 프레임 속도, 포그라운드 서비스 알림, 진단 (CameraX 버전, 렌즈별 기능, 현재 카메라 사용 주체), 버전 기록
* `기능` 스크립트가 카메라, 해상도 또는 프레임 속도를 지정하지 않으면 설정 화면의 기본값을 사용합니다 (초기값은 후면 카메라, 640x480, 기기 자체 프레임 속도). 스크립트가 지정한 값이 항상 우선합니다
* `기능` 업데이트 확인: 설정 화면에서 공식 플러그인 색인에 등록된 새 릴리스와 설명을 확인하고 특정 릴리스를 무시할 수 있습니다. 설정 화면을 열 때 자동으로 확인합니다 (최대 12시간마다 한 번, 끌 수 있음). 네트워크 권한은 업데이트 확인에만 쓰이며, 플러그인은 카메라 화면이나 사진을 업로드하지 않습니다
* `기능` ABI별 설치 패키지 (arm64-v8a, armeabi-v7a, x86_64, x86)와 모든 기기에서 쓸 수 있는 universal 패키지를 제공하며, CameraX와 Compose에 딸린 네이티브 라이브러리는 16 KB 메모리 페이지에 맞춰 정렬되어 있습니다
* `기능` 10개 언어의 README, 플러그인 센터 안내, 변경 기록을 JSON 원본에서 일괄 생성
* `의존성` Jetpack CameraX 1.6.2 추가 (카메라 열기, 사진 촬영, 프레임과 뷰파인더 제공)
* `의존성` Jetpack Compose BOM 2026.09.00 추가 (플러그인 화면)
