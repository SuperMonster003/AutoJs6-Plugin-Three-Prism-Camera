# v1.0.0

###### 2026/11/05

* `提示` 開發預覽: 相機核心已可供 AutoJs6 呼叫 (開啟相機, 連續擷取影格, 拍照, 預覽與各項控制), 拍攝頁與 camera 指令碼模組尚未交付
* `提示` 需要 AutoJs6 6.8.1 (6641) 或更高版本 (確切的最低版本號待宿主端變更完成後回填)
* `提示` 目前圖示為候選圖案, 之後可能更換
* `新增` 外掛骨架: Wake 啟用協定與外掛中心身分服務
* `新增` 相機能力服務: 同一時間只有一個工作階段能使用相機, 被占用時回報占用者; 使用相機期間顯示前景通知, AutoJs6 結束後相機立即釋放, 通知隨之消失
* `新增` 連續擷取影格: RGBA 影格經 3 塊共用記憶體 (Android 8.1 以上) 或 3 個暫存檔 (Android 7.0 - 8.0) 輪流交給 AutoJs6, 可設定解析度與影格率; 來不及處理的影格會被略過並計數
* `新增` 拍照: JPEG 以唯讀檔案交給 AutoJs6, 並附帶寬高, EXIF 方向, 位元組數與是否鏡像; 可設定畫質, 解析度與閃光模式; 鏡像照片只改寫 EXIF 方向, 不重新編碼; 個別相機 (例如 Android 7.0 模擬器) 不寫入照片方向, 外掛會補寫 90 / 270 度的方向, 使照片依手持方向顯示 (漏寫的 180 度無法辨識)
* `新增` 預覽: 畫面顯示在 AutoJs6 提供的介面上, 旋轉螢幕後方向隨之調整; 前置鏡頭的預覽預設鏡像, 影格與照片預設不鏡像; 顯示預覽的介面關閉後自動停止預覽, 擷取影格與拍照照常進行
* `新增` 控制: 手電筒, 閃光模式, 變焦 (倍率或線性), 曝光補償, 點按對焦與測光; 裝置不支援的項目 (例如前置鏡頭的閃光燈) 回報 UNSUPPORTED
* `新增` 相機權限: 未授權時開啟相機回報 PERMISSION_DENIED, 可以要求授權; Android 13 以上同時要求通知權限, 以顯示相機使用中的通知
* `新增` 依 ABI 分別提供安裝套件 (arm64-v8a, armeabi-v7a, x86_64, x86), 另有適用於所有裝置的 universal 安裝套件; CameraX 與 Compose 內建的原生程式庫已按 16 KB 記憶體分頁對齊
* `新增` 10 種語言的 README, 外掛中心說明與更新日誌, 由 JSON 來源檔案統一產生
* `相依性` 附加 Jetpack CameraX 版本 1.6.2 (開啟相機, 拍照, 擷取影格與取景)
* `相依性` 附加 Jetpack Compose BOM 版本 2026.09.00 (外掛介面)
* `相依性` 附加 AndroidX Activity Compose 版本 1.12.2
* `相依性` 附加 AndroidX Core KTX 版本 1.16.0
* `相依性` 附加 AndroidX ExifInterface 版本 1.4.2 (寫入照片的 EXIF 方向)
