# v1.0.0

###### 2026/11/08

* `提示` 指令碼 API 見 [AutoJs6 文件 > 相機 (Camera)](https://docs.autojs6.com/#/camera)
* `提示` 指令碼使用 camera 模組需要 AutoJs6 6.8.1 (內部版本號 6641) 或更高版本; 外掛的取景頁與設定頁不依賴 AutoJs6
* `提示` 目前圖示為候選圖案, 之後可能更換
* `新增` 外掛骨架: Wake 啟用協定與外掛中心身分服務
* `新增` 相機能力服務: 同一時間只有一個工作階段能使用相機, 被占用時回報占用者; 使用相機期間顯示前景通知, AutoJs6 結束後相機立即釋放, 通知隨之消失
* `新增` AutoJs6 在背景執行或手機停在鎖定畫面時 (Android 11 以上), 系統不允許使用相機, 此時開啟相機會回報 CAMERA_DISABLED (視系統而定, 開啟時直接回報錯誤, 或工作階段先回報再關閉), 回到前景後再開啟即可正常使用; 在前景開啟的工作階段轉到背景或關閉螢幕後照常擷取影格
* `新增` 連續擷取影格: RGBA 影格經 3 塊共用記憶體 (Android 8.1 以上) 或 3 個暫存檔 (Android 7.0 - 8.0) 輪流交給 AutoJs6, 可設定解析度與影格率; 影格在格式轉換時即依螢幕方向轉正, AutoJs6 只需視需要鏡像, 每個影格耗時更低; 來不及處理的影格會被略過並計數
* `新增` 拍照: JPEG 以唯讀檔案交給 AutoJs6, 並附帶寬高, EXIF 方向, 位元組數與是否鏡像; 可設定畫質, 解析度與閃光模式; 鏡像照片只改寫 EXIF 方向, 不重新編碼; 個別相機 (例如 Android 7.0 模擬器) 不寫入照片方向, 外掛會補寫 90 / 270 度的方向, 使照片依手持方向顯示 (漏寫的 180 度無法辨識)
* `新增` 預覽: 畫面顯示在 AutoJs6 提供的介面上, 旋轉螢幕後方向隨之調整; 前置鏡頭的預覽預設鏡像, 影格與照片預設不鏡像; 顯示預覽的介面關閉後自動停止預覽, 擷取影格與拍照照常進行
* `新增` 控制: 手電筒, 閃光模式, 變焦 (倍率或線性), 曝光補償, 點按對焦與測光; 裝置不支援的項目 (例如前置鏡頭的閃光燈) 回報 UNSUPPORTED
* `新增` 相機權限: 未授權時開啟相機回報 PERMISSION_DENIED, 可以要求授權; Android 13 以上同時要求通知權限, 以顯示相機使用中的通知
* `新增` 取景頁: 從啟動器開啟, 可切換鏡頭, 開關手電筒, 用滑桿或雙指縮放變焦, 輕觸畫面對焦; 拍下的照片只顯示畫面與解析度, 不會儲存; 前置鏡頭的畫面在螢幕上鏡像顯示, 照片不鏡像
* `新增` 指令碼呼叫 camera.capture({ ui: true }) 時開啟同一個取景頁: 照片直接交給指令碼, 取消則傳回 null; AutoJs6 在背景執行導致取景頁無法開啟時, 10 秒後回報 UI_REQUIRES_FOREGROUND, 不會一直等待
* `新增` 相機正被指令碼使用時, 取景頁顯示是哪個指令碼, 並可停止該指令碼後接手相機
* `新增` 設定頁 (取景頁右上角): 外觀 (語言, 夜間模式, 主題色, 啟動器圖示), 相機與通知權限, 預設鏡頭, 預設分析解析度與影格速率, 前景服務通知, 診斷 (CameraX 版本, 各鏡頭的功能, 目前使用相機的一方) 與版本記錄
* `新增` 指令碼沒有指定鏡頭, 解析度或影格速率時, 使用設定頁中的預設值 (初始為後置鏡頭, 640x480 與裝置本身的影格速率); 指令碼指定的值一律優先
* `新增` 檢查更新: 在設定頁查看官方外掛索引中的新版本及其說明, 可以忽略某個版本; 開啟設定頁時自動檢查 (每 12 小時最多一次, 可以關閉); 網路權限只用於檢查更新, 外掛不會上傳相機畫面與相片
* `新增` 依 ABI 分別提供安裝套件 (arm64-v8a, armeabi-v7a, x86_64, x86), 另有適用於所有裝置的 universal 安裝套件; CameraX 與 Compose 內建的原生程式庫已按 16 KB 記憶體分頁對齊
* `新增` 10 種語言的 README, 外掛中心說明與更新日誌, 由 JSON 來源檔案統一產生
* `相依性` 附加 Jetpack CameraX 版本 1.6.2 (開啟相機, 拍照, 擷取影格與取景)
* `相依性` 附加 Jetpack Compose BOM 版本 2026.09.00 (外掛介面)
* `相依性` 附加 AndroidX Activity Compose 版本 1.12.2
* `相依性` 附加 AndroidX Core KTX 版本 1.16.0
* `相依性` 附加 AndroidX ExifInterface 版本 1.4.2 (寫入照片的 EXIF 方向)
* `相依性` 附加 Material Color Utilities (MaterialKolor) 版本 4.1.1 (外掛介面的主題色)
